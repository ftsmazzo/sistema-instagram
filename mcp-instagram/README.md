# MCP Instagram — Máquina de Vendas

Servidor MCP (stdio) para **Claude Desktop** e Cursor operar Instagram via Graph API.

Guia completo: [`docs/MCP-INSTAGRAM-CLAUDE.md`](../docs/MCP-INSTAGRAM-CLAUDE.md)

```bash
npm install
npm run build
cp .env.example .env   # preencha IG_USER_ID + INSTAGRAM_ACCESS_TOKEN
```
